# Perfect Cleaning Solutions website

Plain HTML + CSS. No build step. To update: edit a file in GitHub (pencil icon) → Commit. The live site updates in about a minute.

- `index.html` – all page content. Search for `EDIT ME` and `[CITY` to find spots to fill in.
- `styles.css` – colors and layout (brand colors at the top).
- `images/` – add `og-image.jpg` (1200×630 photo used when the link is shared).
- `robots.txt`, `sitemap.xml` – help search engines find the site. Update `lastmod` in sitemap.xml when you make big changes.

Rule of thumb: the FAQ text in the visible page and the FAQ data in the `<head>` should say the same thing.
